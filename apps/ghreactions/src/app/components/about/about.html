GitHub Reactions

GitHub Reactions shows which issues, pull requests and comments get the most reactions on GitHub: for the most-followed developers, and for any public account you search.

Most reacted users Search for a user

Most reacted users

We follow GitHub's 1,000 most-followed users and refresh each one about once a day. Every profile lists their most reacted issues and pull requests, plus their most reacted recent issue comments. Reaction totals cover those top items, not everything a user has posted.

Search

Search any public account to fetch its activity live from the GitHub GraphQL API, and filter by state and reactions:

  • Issues opened by a user
  • Pull requests opened by a user
  • Issue comments by a user
  • Commit comments by a user

Privacy

Everything shown is public GitHub data. We don't store your searches or the usernames you search. Visits are counted with Plausible, which uses no cookies and collects no personal data.

Built with

  • Angular with server-side rendering
  • NG-Zorro for UI components
  • Firebase App Hosting, Cloud Functions and Firestore
  • GitHub GraphQL API
