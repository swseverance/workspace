Add access to library functions like `sin`, `exp`, and `pow`. See `<math.h>` in Appendix B, Section 4.

A word of lower case letters is a command. `sin` and `exp` replace the top element `x` with sin(x) and e<sup>x</sup>; `pow` pops `y`, then `x`, and pushes x<sup>y</sup>. Report any other word as an unknown command, as the calculator does for other characters.
