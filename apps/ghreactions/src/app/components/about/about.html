GitHub Reactions

GitHub Reactions shows which issues, pull requests and comments get the most reactions on GitHub. There are two ways to look at a user:

  • Snapshot. A saved profile of the user's most reacted items, refreshed about once a day. It loads instantly and puts the user in a ranking, but only exists for GitHub's most-followed users.
  • Live search. Everything a user has posted, fetched from GitHub when you ask. It works for any public account and can be filtered, but takes a moment and isn't ranked against anyone.

Snapshots: the most reacted users

We follow GitHub's 1,000 most-followed users and refresh each one about once a day. Every profile lists their most reacted issues and pull requests, plus their most reacted recent issue comments. Reaction totals cover those top items, not everything a user has posted. Users are ranked by those totals, and the ranking can be filtered by username. Each snapshot links to the live search for the same user.

Live search: any public account

Search any public account to fetch its activity live from the GitHub GraphQL API, and filter by state and reactions:

  • Issues opened by a user
  • Pull requests opened by a user
  • Issue comments by a user
  • Commit comments by a user

Privacy

Everything shown is public GitHub data. We don't store your searches or the usernames you search. Visits are counted with Plausible, which uses no cookies and collects no personal data.
