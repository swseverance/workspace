GitHub Reactions

GitHub Reactions shows which issues, pull requests and comments get the most reactions on GitHub. See your own, or anyone's:

Most reacted users

Snapshots

A snapshot is one user's most reacted issues and pull requests, plus their most reacted recent issue comments, saved so the page loads instantly. Enter any public GitHub username to get one. A new snapshot takes a few seconds to build, is refreshed from time to time, and is kept for {{ snapshotDays }} days. Reaction totals cover those top items, not everything a user has posted.

Most reacted users

We keep snapshots of GitHub's 1,000 most-followed users permanently, refresh each about once a day, and rank them by their reaction totals. The ranking can be filtered by username. Snapshots you ask for aren't part of it.

Live search

Every snapshot links to a live search of the same account, which fetches straight from the GitHub GraphQL API. It's slower and unranked, but covers everything, with filters by state and reactions:

  • Issues opened by a user
  • Pull requests opened by a user
  • Issue comments by a user
  • Commit comments by a user

Privacy

Everything shown is public GitHub data. We don't store your searches or the usernames you search. Visits are counted with Plausible, which uses no cookies and collects no personal data.
