Add the commands to print the top elements of the stack without popping, to duplicate it, and to swap the top two elements. Add a command to clear the stack.

Use `?` to print the top element without popping it, in the same format as a newline does; `d` to duplicate it; `s` to swap the top two elements; and `c` to clear the stack. When there aren't enough elements, `?` and `d` print `error: stack empty` and `s` prints `error: can't swap, fewer than two elements`.
